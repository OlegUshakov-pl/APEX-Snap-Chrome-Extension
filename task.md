Главная задача этого приложения это создание поиск и сохранение и отправка маленьких слепков в виде файлов protobuf

Еще есть серверноe приложние на FastApi где будут хранится слепки

У на есть страница поиска и страница настроек.

1. Небходимо на страницу settings.html над кнопкой Save Settings добавить Browse справа написать File Storage Path 
это выбор места где будут храниться слепки .proto

На главной странице search.html слева на той же высоте что и шестеренка добавить  большой +, при нажатии на этот + будет плавно выпадающий список на страницы New,  File List

2. Давай создадим пустую страницу New File, background главной страницы 
3. Давай создадим пустую страницу List File, background главной страницы 
4. Добавим ссылку на каждую страницу в меню на +
